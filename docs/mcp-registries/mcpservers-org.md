## How it works

Despite being list-shaped, mcpservers.org takes submissions through a web form only:
https://mcpservers.org/submit. No PR path.

## Prerequisites

- Shared listing copy ready (readiness report §5.1)
- Public repo ([DEV-3869](https://linear.app/modem-dev/issue/DEV-3869)) preferred as link target — per parent ticket [DEV-3872](https://linear.app/modem-dev/issue/DEV-3872)

## Steps

1. Submit at https://mcpservers.org/submit with the §5.1 copy, endpoint `https://mcp.modem.dev/mcp`, docs + repo links.
2. Batch with [mcp.so](mcp-so.md) in the same sitting (same copy, same ticket).
