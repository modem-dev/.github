## How it works

Submit via mcp.so's form; free review queue. A paid fast-track exists — **skip it** unless we
decide we want featured placement.

## Prerequisites

- Shared listing copy ready (readiness report §5.1)
- Logos exported ([DEV-3877](https://linear.app/modem-dev/issue/DEV-3877))
- Best done after the [official registry publish](official-mcp-registry.md) and public repo ([DEV-3869](https://linear.app/modem-dev/issue/DEV-3869)) so the listing has canonical link targets — per parent ticket [DEV-3872](https://linear.app/modem-dev/issue/DEV-3872)

## Steps

1. Fill the mcp.so submit form with the §5.1 listing copy: name, description, `https://mcp.modem.dev/mcp` endpoint, docs link, repo link, logo.
2. Decline the paid fast-track.
3. Batch with [mcpservers.org](mcpservers-org.md) in the same sitting (same copy, same ticket).

## Done when

- Listing approved and live with current metadata
